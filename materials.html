The tools are meant to be used, not just read about. The visualization system runs on ordinary desktop Linux and macOS for pthreads work, and extends to microcontrollers running FreeRTOS and robots running ROS 2. Materials will be posted here as they are released.

Prior work this builds on

The toolchain extends ThreadMentor and ConcurrentMentor, NSF-funded systems for teaching multithreaded programming through visualization that have anchored concurrency education at the team's institutions for two decades. ThreadMentor pairs a C++ class library implementing the synchronization abstractions used in concurrency pedagogy with a visualization system that shows the dynamic behavior of threaded programs. Instrumentation is built into the library, so student programs and the visualization run together without a separate instrumentation step.

This project modernizes that foundation and retargets it for engineering audiences: new instrumentation for ROS 2 and FreeRTOS, a rebuilt visualization interface, and packaging into modular curricular components.
